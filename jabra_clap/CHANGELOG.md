# Changelog

Alle wesentlichen Änderungen an Jabra Double Clap werden hier dokumentiert.

## 1.0.7

- Branding mit eigenem Icon und Logo
- Beschreibung und Maintainer-Angabe ergänzt
- Metadaten bereinigt
- Aktuelle Klatsch-Charakteristik beibehalten

## 1.0.3

- Erweiterte Klatsch-Charakteristik eingeführt
- Crest Factor ergänzt
- Sharpness ergänzt
- Maximale Impulsdauer ergänzt
- Bessere Abgrenzung von Sprache und länger anhaltenden Geräuschen

## 1.0.2

- Home-Assistant-Auslösung auf lokalen Webhook umgestellt
- Abhängigkeit vom Supervisor-Token entfernt

## 1.0.0

- Erste funktionsfähige Version
- Doppelimpuls-Erkennung über Jabra-Mikrofoneingang
- Einstellbare Peak-, RMS- und Zeitfensterwerte
