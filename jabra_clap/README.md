# Jabra Double Clap

![Jabra Double Clap](logo.png)

**Doppelklatsch-Erkennung für Home Assistant · entwickelt von Filo**

Jabra Double Clap überwacht den Mikrofoneingang eines Jabra Link 390 und erkennt zwei kurze, scharfe Klatschimpulse. Bei erfolgreicher Erkennung wird ein lokaler Home-Assistant-Webhook ausgelöst.

### Merkmale

- Doppelklatschen statt einfacher Lautstärkeschwelle
- Peak-, RMS-, Crest-Factor- und Sharpness-Auswertung
- Einstellbares Zeitfenster zwischen beiden Klatschern
- Lokaler Webhook
- Keine Audioaufzeichnung
- Geeignet zur parallelen Nutzung mit Assist Satellite

Weitere Hinweise findest du im Tab **Dokumentation**.
